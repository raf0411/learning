# Loop growth and remembering earlier values

## Separate loops versus nested loops

Two separate loops add their work:

```text
[ n visits ] -> [ n visits ]

total = n + n = 2n
growth = O(n)
```

Nested loops multiply their work because the entire inner loop runs for every outer-loop item:

```text
outer item 0 -> n inner visits
outer item 1 -> n inner visits
...
outer item n - 1 -> n inner visits

total = n * n
growth = O(n^2)
```

## Exact duplicate comparisons versus growth

The exhaustive duplicate scan visits an `n` by `n` grid. The diagonal represents self-comparisons:

```text
        other index
          0  1  2  3
current 0  X  o  o  o
current 1  o  X  o  o
current 2  o  o  X  o
current 3  o  o  o  X
```

The exact number of non-self value comparisons is:

$$
C(n) = n(n - 1) = n^2 - n
$$

When the input doubles, every occurrence of `n` must be replaced by `2n`:

$$
C(2n) = (2n)^2 - 2n = 4n^2 - 2n
$$

This is not exactly four times the work for finite `n`; the ratio approaches four as `n` grows. The `n^2` term determines the long-term growth shape, so the procedure is quadratic: `O(n^2)`.

## Checking each pair once

For pair-sum, reversed pairs contain no new information. Keeping only the upper triangle checks each pair once:

```text
        partner index
          0  1  2  3
current 0  -  o  o  o
current 1     -  o  o
current 2        -  o
current 3           -
```

The exact pair count is:

$$
\frac{n(n - 1)}{2}
$$

Dividing by two reduces the exact work but does not change quadratic growth: `O(n^2)`.

## Trading memory for time

```text
Approach          Expected time   Extra space
Nested pairs      O(n^2)          O(1)
Set-based scan    O(n)            O(n)
```

A set-based scan maintains this invariant:

```text
seen contains exactly the input values from earlier indices
```

For duplicate detection:

```text
check whether current is in seen
if not, add current
```

For pair-sum, start from the original requirement:

$$
\text{current} + \text{partner} = \text{target}
$$

Solve for the missing partner:

$$
\text{partner} = \text{target} - \text{current}
$$

Then:

```text
check whether partner is in seen
if not, add current (not partner)
```

Checking before adding prevents one index from being reused as both members of the pair.
