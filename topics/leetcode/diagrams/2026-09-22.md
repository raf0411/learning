# Nested loops: one fixed position, one moving position

This note visualizes the exhaustive duplicate-checking procedure for:

```text
[4, 1, 2]
```

The two loops have different jobs:

```text
outer loop: choose one current position
inner loop: visit every comparison position from the beginning
```

Each row below is one complete run of the inner loop. The diagonal cells are skipped because both indices refer to the same position.

```text
                         other position
                       0 (4)    1 (1)    2 (2)
                    +---------+---------+---------+
current      0 (4)  |  skip   | 4 == 1  | 4 == 2  |
position            +---------+---------+---------+
             1 (1)  | 1 == 4  |  skip   | 1 == 2  |
                    +---------+---------+---------+
             2 (2)  | 2 == 4  | 2 == 1  |  skip   |
                    +---------+---------+---------+
```

Execution goes across one row, then returns to the first column of the next row:

```text
(0,0) skip -> (0,1) -> (0,2)
                              |
                              v
(1,0)      -> (1,1) skip -> (1,2)
                              |
                              v
(2,0)      -> (2,1)      -> (2,2) skip
```

The key reset is:

```text
after current position 0 finishes:
    current position becomes 1
    comparison position restarts at 0
```

Therefore the first real comparison on the second row is `1 == 4`.

The procedure returns `True` immediately if any non-skipped comparison matches. It returns `False` only after every row finishes without a match.
