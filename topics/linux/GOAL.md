# Goal

## Long-term objective

Become confident and independent using the Linux terminal for everyday work,
technical projects, and basic investigation without needing step-by-step help.

## Desired capability

The learner can:

- orient within an unfamiliar Linux filesystem and navigate deliberately;
- create, copy, move, rename, link, archive, organize, and remove files safely;
- inspect and edit text files and choose appropriate tools for files and logs;
- understand shell syntax, quoting, variables, expansion, pipes, redirection,
  standard streams, exit status, and command chaining;
- search for files and transform text with common command-line tools;
- understand and modify standard ownership and permissions safely;
- use basic package-manager operations and verify installed software;
- inspect and control processes, jobs, services, logs, and basic resource usage;
- use common network diagnostic tools, SSH, and secure file transfer;
- write and troubleshoot small Bash scripts;
- use local and official documentation to solve unfamiliar terminal tasks;
- verify command results, diagnose ordinary mistakes, and recover safely.

## Success criteria

Complete an unfamiliar integrated terminal scenario without procedural hints:

1. inspect the environment and locate relevant files and commands;
2. organize and protect a small project safely;
3. inspect, edit, search, and transform text data;
4. query or install software with the system package manager;
5. investigate a process, service, log, resource, or network question;
6. automate a small repeated task with Bash;
7. verify every material result and explain the commands and safety checks used;
8. present the finished work as a reproducible portfolio project with sanitized
   examples, a README, test evidence, and a troubleshooting case study.

## Constraints

- Begin at beginner level and build from observed terminal behavior.
- Keep the current filesystem-orientation phase and complete its existing
  checkpoint before advancing.
- Favor safe exercises in disposable directories, files, processes, and a
  disposable Linux virtual machine.
- Distinguish portable shell behavior from Linux-specific behavior while the
  learner is practicing on macOS.
- Use the Linux Foundation Introduction to Linux (LFS101) outline as the main
  beginner coverage check.
- Prefer actual machine output, installed documentation, and official upstream
  or distribution documentation as lesson evidence.
- Defer advanced system administration, storage engineering, boot recovery,
  security policy administration, containers, and virtualization management.
