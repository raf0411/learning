# Goal

## Long-term objective

Become comfortable using the Linux terminal independently for everyday file
management, content inspection, searching, text processing, and basic system
resource investigation.

## Desired capability

The learner can:

- orient themselves in an unfamiliar filesystem and navigate deliberately;
- create, copy, move, rename, organize, and remove files safely;
- choose an appropriate command to inspect files and logs;
- locate commands, files, and important system resources;
- combine text-processing tools to answer practical questions;
- inspect CPU, memory, disk, directory, and command-time information;
- use command help and observed output to solve unfamiliar terminal tasks;
- verify the result of a command and recover from ordinary mistakes.

## Success criteria

Complete an integrated, unfamiliar terminal scenario without procedural hints:
inspect the environment, organize a small project, find and analyze requested
data, report resource usage, and explain the commands and safety checks used.

## Constraints

- Begin at beginner level and build from observed terminal behavior.
- Favor safe exercises in disposable directories.
- Distinguish portable shell behavior from Linux-specific behavior when the
  learner is practicing on macOS or another Unix-like system.
