## Load guard (line 32)

- Original:
  ```bash
  if command -v uptime > /dev/null && command -v sed 's/.*load average: //'; then
  ```
- The learner ran the script and pasted output with `/usr/bin/sed` on the first line, but did not point it out. The learner then asked "are u saying there is something wrong with the script?"
- Two problems taught:
  1. The second `command -v` was not silenced.
  2. The sed expression was passed to `command -v` as a second "name".
- **Tutor experiment (macOS Bash 5.3, not the VM):** `command -v sed bogusxyz` returned status 0 when at least one name was found. So the `if` succeeded by accident.
- First fix: added only `> /dev/null`. The expression was still there.
- The learner asked "what are we comparing then". The tutor clarified that `&&` joins two yes/no existence checks, then gave the corrected line:
  ```bash
  if command -v uptime > /dev/null && command -v sed > /dev/null; then
  ```
- **Misconception:** `command -v` needs the command's usage arguments. Taught that it takes only command names; the arguments matter only when the command runs.
- The stray line printed before `== System ==` because the script computes all values before any `printf`. The learner pasted the full script, which confirmed this.
