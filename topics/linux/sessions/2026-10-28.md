## Important mental-model updates

```text
.       current directory
..      parent directory
../..   parent of the parent
~       current user's home directory
/       filesystem root
```

- A command argument separated by whitespace is a separate path.
- `/` inside a path expresses traversal or nesting.
- `mkdir -p` creates missing parent directories.
- Successful commands are not enough: verification output must contain every
  requested branch.
