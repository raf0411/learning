## Step 7b: required-dependency check

First attempt (placed at the top; the reason given was "check dependencies before running"):
```bash
commands=("grep", "awk", "sort", "uniq")
for cmd in commands; do
     status=$(command -v "$cmd"; echo "$?")
     if [ "$status" -ne 0 ]; then
         printf 'missing required command: <%s>\n' "$cmd" >&2
         exit 3
```
- `>&2` was written correctly in production. This review item is now satisfied.
- **Bugs, found one at a time:**
  1. Missing `fi` and `done`. The learner found both using `bash -n` (introduced today).
  2. `for cmd in commands` looped over the literal word. The run printed `missing required command: <commands>`.
     - The prediction for the test line was "grep awk sort uniq"; the learner ran the script instead of the test line.
     - Fix: `"$commands"`. The tutor's question about `$` led to it.
  3. Commas inside the array: `<grep,>` appeared. The learner noticed the comma but not why.
     - Taught: elements are separated by spaces, and `"$arr"` gives only the first element (`"${arr[@]}"` gives all of them).
     - The learner switched to `for cmd in grep awk sort uniq`.
  4. `status=$(command -v ...; echo $?)` captured the path and the status together, so `[` gave "integer expected".
     - The learner had suspected the `status`/`-ne` line before seeing this.
     - **Unprompted**, the learner added a debug print of `$status` and a fake `nos` command to test the failure path.
     - The tutor showed that for real commands `[` errored, the `if` treated that as false, and the loop passed by accident.
- **`if` runs any command:**
  - First answer: `if ! [ -f "$status" ]`. Incorrect.
  - Taught that `if` branches on any command's exit status; `[` is just one command.
  - Then wrote `if command -v "$cmd"; then printf missing...`, which has inverted polarity.
  - Asked to trace `cmd=grep`, the learner fixed it with an empty `then` branch. `bash -n` reported a syntax error.
  - Then `if ! command -v "$cmd" > /dev/null ; then`, with correct `!` spacing and output **silenced unprompted**.
- Run with `nos` in the list: `missing required command: <nos>`, status 3. After removing `nos`: 6/6 PASS.
- `<%s>` angle brackets: these came from the tutor's ambiguous spec notation. The learner was asked to remove them; removal is **not verified**.
