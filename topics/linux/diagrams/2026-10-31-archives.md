# Archives — 2026-10-31

An archive bundles files and their path structure into one file. Compression
is a separate operation that can reduce the space needed to represent data.
The first tar lab requests archiving without compression.

```text
project/                         project.tar
├── notes.txt       --create-->  [stored paths + contents]
└── data/                             |
    └── items.txt                     +-- list: display stored paths
                                      |
                                      +-- extract into restored/
                                                |
                                                v
                                         restored/project/
                                         ├── notes.txt
                                         └── data/
                                             └── items.txt
```

Creation reads the source and writes the archive. Listing reads the archive
without creating extracted files. Extraction reads the archive and recreates
its stored paths under the chosen destination. These operations leave the
source project in place in this lab.

| Option | Purpose |
| --- | --- |
| `-c` | Create |
| `-t` | List stored entries |
| `-x` | Extract |
| `-f archive` | Select the archive filename |
| `-C directory` | For this extraction, work inside that destination |

Inspection before extraction reveals the stored paths. Using a fresh empty
destination avoids replacing unrelated existing files. `-C` affects tar's
working directory, not the shell's working directory.
