# Tar with gzip compression — 2026-11-01

A tar archive and compression solve different problems:

```text
many paths and contents             one archive representation

project/                    tar     project.tar
├── notes.txt             ------->  [paths + metadata + contents]
└── data/
    └── items.txt

project/                 tar+gzip   project.tar.gz
├── notes.txt             ------->  gzip([paths + metadata + contents])
└── data/
    └── items.txt
```

`tar` provides the archive structure. In the installed `bsdtar`, `-z` applies
gzip compression to that archive representation. The stored project pathnames
can therefore be the same even though the two archive files use different
representations and normally have different byte sizes.

```text
Create:   tar -czf project.tar.gz project
                    |
                    +-- gzip compression

List:     tar -tzf project.tar.gz
             |
             +-- display stored paths; create no extracted tree

Extract:  tar -xzf project.tar.gz -C restored-gzip
             |                         |
             |                         +-- extraction destination
             +-- recreate stored paths
```

The lab uses an empty destination because extraction writes filesystem entries
and may replace existing destination files. Listing first exposes the stored
paths before that write operation.
