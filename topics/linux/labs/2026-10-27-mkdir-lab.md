## Foundation

`mkdir` means **make directory**. Its basic form is:

```text
mkdir DIRECTORY...
```

One command can receive one or several directory paths. Normally, each parent
directory in a path must already exist. The `-p` option tells `mkdir` to create
missing parent directories as needed.

## Synthesis

- What does `mkdir` change on the filesystem?

  it changes the the current directory, so it has a new directory

- Why did `mkdir docs scripts data` create three siblings?

  because we separate it by spaces, and not specifying the nested path and not using -p

- When is `mkdir -p` useful?

  its to automatically create directory even with nested path even if it doesn't exists yet

- If your current directory is `mkdir-practice`, are the paths
