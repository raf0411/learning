# Verify `umask 027` — 2026-11-10

Use the Ubuntu terminal. This experiment creates a fresh disposable directory.
The changed umask applies only inside a child Bash process, so the interactive
shell should retain its original `0002` mask.

## Predictions — preserved

| New object | Requested mode | After `umask 027` |
|---|---:|---|
| Regular file | `666` (`rw-rw-rw-`) | `640` (`rw-r-----`) |
| Directory | `777` (`rwxrwxrwx`) | `750` (`rwxr-x---`) |

The first directory answer omitted group `x`, then the learner corrected it:
mask digit `2` removes group `w` only, leaving group `r-x`.

## Run and inspect

```bash

ls -ld "$umask_lab/new-file" "$umask_lab/new-dir"
printf 'interactive-shell-umask='; umask
```
