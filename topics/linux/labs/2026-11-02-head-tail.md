# Lab — Inspect the beginning and end with `head` and `tail`

Date: 2026-11-02

## Why these tools exist

`less` is useful when you want to navigate or search interactively. Sometimes
you need only a bounded piece of a file and want the command to print that piece
and immediately return to the shell:

- `head -n COUNT FILE` prints the first `COUNT` lines.
- `tail -n COUNT FILE` prints the last `COUNT` lines.

Like `cat` and `less`, these uses inspect the file; they do not edit it.
