# Lab — Use `man` to discover how `tail` follows a file

Date: 2026-11-02

## Why local documentation matters

You do not need to memorize every option. `man COMMAND` opens the installed
manual page for a command. On this machine, the manual is normally displayed
through a pager, so the navigation and search controls practiced with `less`
apply again.

This lab uses the installed `tail` documentation as the authority for this
machine's version.

## 6 — Focused correction: `-f` versus `-F`

Keep the original predictions and explanations above unchanged as learning
evidence.

Reading `man tail` does not modify the program or manual. `/additional` changed
only the pager's temporary search position.

For a named file, the installed manual describes this distinction:

```text
before rotation:
app.log   -> file identity A
tail -f   -> open file A

after rotation:
app.log.1 -> file identity A   (the old log was renamed)
app.log   -> file identity B   (a new log was created at the original path)

tail -f   may remain on A
tail -F   watches the pathname and reopens B
```

`-F` includes follow behavior and additionally checks whether the named path
has been replaced by a different file identity. The manual's standard-input
sentence is a special case; this lab's command used a named file.
