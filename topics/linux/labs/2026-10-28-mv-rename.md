# Lab — Renaming a File with `mv`

Date: 2026-10-28

## Purpose

Discover how `mv` changes a file's pathname and contrast that behavior with
`cp`, which leaves the original path in place.

All changes remain inside the disposable `move-practice` tree.

## Mental model to test

This command has two path operands:

```bash
mv SOURCE TARGET
```

For this first experiment, `SOURCE` names an existing file and `TARGET` names a
new path in the same directory. The experiment will show whether `mv` leaves
two files, as `cp` would, or changes which pathname reaches the file.
