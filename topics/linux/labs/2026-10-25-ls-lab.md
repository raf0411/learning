# Lab 1 — Seeing a Directory with `ls`

Date: 2026-10-25

## Mental model

A useful basic command shape is:

```text
command  options  path
```

For `ls`:

```text
ls [options] [path]
```

- A **path** tells `ls` which directory to inspect.
- An **option** changes how `ls` reports what it finds.
- With no path, `ls` uses `.`, which means the current directory.

Therefore these inspect the same place:

```bash
ls
```

```bash
ls .
```

## Experiment 2 — Hidden entries

On Unix-like systems, names beginning with `.` are normally omitted by plain
`ls`. This is a display convention, not a security feature. Option `-a` means
show all entries.

Predict whether `ls -a` will display any names that plain `ls` did not:

yes

Run:

```bash
ls -a
```

Record only the additional names:

```text
raffi@Raffis-Mac ls-practice % ls -a
.		..		.environment	archive		report.txt	scripts
raffi@Raffis-Mac ls-practice %
```

You should see `.` and `..`. Based on the earlier mental model and probe, what
does each one refer to?

- `.`: upper level directory
- `..`: two upper level directory
