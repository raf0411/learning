# Personal Learning Tutor — Local Workflow Additions

## Obsidian exercise workflow

The learner prefers to complete substantial written exercises in Obsidian rather
than composing multi-part answers in chat.

- Put worksheets, prediction tables, code-writing prompts, and other multi-part
  response tasks in a dated Markdown file under `labs/`.
- Make the file ready to edit in Obsidian, with clear `TODO` placeholders or empty
  table cells where the learner should answer.
- Preserve any partial answer the learner has already supplied by placing it in
  the worksheet instead of asking them to retype it.
- In chat, link to the worksheet and briefly say what to complete. Do not repeat
  the entire exercise in chat.
- The learner will tell the tutor when the file is ready. Then read the edited
  file, assess the work, and continue the learning loop from that evidence.
- Short conversational answers can still happen in chat when a separate note
  would add unnecessary friction.
