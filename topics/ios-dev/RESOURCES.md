# RESOURCES

Use these to answer a specific implementation question, then apply the answer.
They are references, not a requirement to read every chapter or copy full apps.

## Language and platform

- [The Swift Programming Language](https://docs.swift.org/latest/documentation/the-swift-programming-language/)
  — primary reference for types, optionals, collections, functions, models,
  protocols, errors, concurrency, and memory management. Match version-sensitive
  details to the installed toolchain.
- [Develop in Swift](https://developer.apple.com/tutorials/develop-in-swift)
  — Apple's examples for Xcode, SwiftUI, data modeling, accessibility, and
  distribution. Use selected sections around a learner-written feature; the
  advanced/AI/spatial chapters are outside the present core path.
- [SwiftUI documentation](https://developer.apple.com/documentation/swiftui)
  — API signatures, ownership/data-flow APIs, navigation, and availability.
- [Pro Git](https://git-scm.com/book/en/v2)
  — version-control concepts and practical local/GitHub workflows; start with
  recording changes and inspecting history before branching/merging.
