# RESOURCES

Selected on 2026-09-21. Use targeted sections alongside practice, not as a front-to-back reading checklist.

- [The Swift Programming Language](https://www.swift.org/documentation/tspl/) — official language reference; use for types, control flow, collections, optionals, functions, and later language features.
- [A Swift Tour](https://docs.swift.org/swift-book/documentation/the-swift-programming-language/guidedtour/) — compact examples for orienting to Swift syntax.
- [Functions](https://docs.swift.org/swift-book/documentation/the-swift-programming-language/functions/) — first targeted documentation exercise: defining/calling functions and parameter/return types. The [official book source](https://github.com/swiftlang/swift-book/blob/main/TSPL.docc/LanguageGuide/Functions.md) is a readable fallback.
- [Apple: Develop in Swift](https://developer.apple.com/tutorials/develop-in-swift) — selected SwiftUI, modeling, persistence, testing, accessibility, and app-development exercises. Follow examples with a learner-designed variation.
- [Apple: Stepping through code and inspecting variables](https://developer.apple.com/documentation/xcode/stepping-through-code-and-inspecting-variables-to-isolate-bugs) — debugger reference for the first inspection lab.
- [Pro Git](https://git-scm.com/book/en/v2) — targeted Git basics and branching reference; practical use must be assessed independently of prior exposure.
