# GOAL

## Destination

Prepare for entry-level Junior iOS Developer applications within approximately
3–4 months of starting on 2026-09-21. Treat this as a planning target, with pace
adjusted to available study time and demonstrated ability.

Become able to design and build portfolio-quality iOS applications independently,
without relying on AI-generated implementations.

## Success criteria

- Turn requirements into manageable tasks and implement features from an empty
  Xcode project or within an unfamiliar codebase.
- Use Swift and SwiftUI fundamentals, APIs, persistence, appropriate architecture,
  debugging tools, Git, testing, and accessibility in practical applications.
- Build approximately 2–4 substantial portfolio projects with distinct strengths;
  personally explain their data flow, technical decisions, tradeoffs, and bugs.
- Complete realistic junior development and take-home-style tasks with decreasing
  assistance, using documentation and debugging tools independently.

## Learning constraints

- Prioritize practical junior employment skills over advanced or niche frameworks.
- Learn primarily through exercises, debugging, feature work, and projects.
- Probe unfamiliar topics before teaching; prefer hints over complete solutions.
- Progress from guided projects to independent work and requirements-only tasks.
- Track implementation, debugging, and explanation separately; guided success is
  not independent mastery.
- Study availability: 5 hours per day, 5 days per week (25 hours per week).
- Primary employment target: junior iOS roles in Indonesia. Also open to
  international remote roles that allow working from Indonesia; not currently
  willing to relocate to another country.
