# GOAL

Become ready to compete for entry-level junior iOS developer roles within roughly 3–4 months of 2026-09-21. Prioritize Indonesia, while remaining open to international remote work and relocation. The timeline is a preparation target, not a hiring guarantee.

## Desired capabilities

- Independently turn a small requirement into working Swift and iOS features.
- Build personally useful apps that can become explainable portfolio projects.
- Diagnose bugs, use documentation, test behavior, and manage changes with Git.
- Develop transferable programming foundations: decomposition, data modeling, control flow, abstraction, data structures, testing, and reasoning about execution.
- Grow toward a broader mobile development career after establishing iOS competence.

## Success criteria

- Build and explain two focused iOS projects, including local persistence and network integration across the portfolio.
- Implement an unfamiliar small feature without procedural hints or generated implementation; documentation is allowed.
- Reproduce and diagnose a bug, justify a fix, and verify it with appropriate checks.
- Explain data flow and design decisions, make a small change to an existing UIKit project, and demonstrate a basic Git workflow.
- Present clear project READMEs, demos, and technical explanations suitable for junior applications and interviews.

## Constraints and preferences

- Fresh graduate; prior coding experience has relied heavily on AI. Rebuild independence through learner-written code and progressive hints.
- Hands-on, project-based study with practical employment fundamentals prioritized.
- Reports availability of five hours per day and regular access to a Mac with Xcode.
- Learn transferable ideas through Swift initially; broaden languages later as needed.
