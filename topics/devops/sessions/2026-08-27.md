## Concepts covered

- `~` expands to the current user's home directory; it is an alternative to an
  absolute home path, not a prefix for it.
- Each unquoted whitespace-separated word is a separate shell argument.
- Every relative source and destination path is resolved from the current
  working directory.
- `mv SOURCE DESTINATION` renames within one directory or moves between
  directories.
- `cp SOURCE DESTINATION` retains the source; `cp SOURCE... DIRECTORY` accepts
  multiple source operands.
- A trailing slash denotes a directory path.
- `cp -i`, `mv -i`, and `rm -i` request confirmation before destructive
  replacement or removal.
- `rmdir` removes empty directories and refuses non-empty ones.
- `--help` can be used to verify an installed command's options.
