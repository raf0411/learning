## Concepts covered

- `head -n` and `tail -n` select lines from the beginning or end of a file.
- `less` is an interactive pager; `g`, `G`, `/pattern`, `n`, and `q` navigate,
  search, repeat a search, and quit.
- `grep PATTERN FILE` prints matching lines; matching is case-sensitive unless
  `-i` is used, and `-n` adds source line numbers.
- Option meanings are command-specific: `head -n` takes a count, while
  `grep -n` is a standalone flag.
- `find START -name PATTERN` searches recursively; quoted wildcards are passed
  to `find`, and `-type f` restricts matches to regular files.
- A pipeline connects the left command's standard output to the right command's
  standard input; changing command order can change the result.
- `>` overwrites standard-output destinations, `>>` appends, `2>` overwrites an
  error-output destination, and `2>>` appends error output.
- Pressing Enter ends a shell command unless continuation syntax is used.
