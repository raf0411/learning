## Concepts covered

- Bash parses a complete command before executing commands or redirections.
- A redirection affects only the command submission to which it is attached.
- A later redirection cannot capture output from an already-finished command.
- An ordinary pipeline carries the left command's stdout, not its stderr.
- Configuration describes intended behavior; logs record observed events. This
  final distinction was introduced but not yet checked.
- The next lesson was scoped around directory roles, Nano's buffer-versus-disk
  state, and archive versus compression.
