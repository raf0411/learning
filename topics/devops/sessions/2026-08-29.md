## Concepts covered

- Each command defines the meaning of its own options; option letters are not a
  shell-wide vocabulary.
- Bash can run both builtins and external programs; being usable in a Bash
  script does not imply that a command is built into Bash.
- `type` reports how Bash resolves a command name. `help` is appropriate for a
  Bash builtin, while external programs commonly provide `--help` and `man`
  documentation.
- `grep -n` prefixes matching output with its 1-based input line number and
  does not consume a numeric argument.
- Commands have separate standard input (`0`), standard output (`1`), and
  standard error (`2`) channels.
- `>`/`>>` select stdout for overwrite/append; `2>`/`2>>` select stderr for
  overwrite/append.
- Pressing Enter submits a command. Text entered afterward is a new command,
  even if it is visually indented like a continuation.
- `wc -l` counts lines in its file operands.
