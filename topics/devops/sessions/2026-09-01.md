## Concepts covered

- Configuration is intended behavior; logs record observed events.
- `/etc`, `/var/log`, `/home`, and `/tmp` organize data by purpose, ownership,
  and expected lifetime.
- Nano edits a buffer; `Ctrl+O` plus `Enter` writes it to disk, while an
  unsaved buffer can be discarded on exit.
- `nano -p` preserves terminal XON/XOFF behavior and does not save files.
- Archiving preserves a file tree in one container; gzip compression is a
  separate space-reduction step selected by `tar -z`.
- A tar archive is a point-in-time copy rather than a live link to its source.
- Inspecting an archive before extracting and using `-C` for a separate restore
  destination reduces collision risk.
