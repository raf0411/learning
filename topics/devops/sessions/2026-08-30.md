# Session — 2026-08-30

## Focus

Short retrieval check on stdout/stderr routing, overwrite versus append, and
the command boundary created by pressing Enter.

## Concepts covered

- `>` overwrites a stdout destination and `2>>` appends to a stderr
  destination.
- Pressing Enter submits the current command as a unit.
- A redirection operator requires its destination in that same submitted
  command.
- If a line ends with `2>>`, Bash reports a syntax error before running the
  command or performing its redirections.
- Text entered at the next prompt is parsed as a new command, not as the
  missing destination of the preceding redirection.
