## Concepts covered

- Nano modifies an in-memory buffer; declining to save discards that buffer
  while leaving the existing disk file unchanged.
- `grep` handles each file operand independently, so one invocation can produce
  successful matches on stdout and missing-file diagnostics on stderr.
- A normal pipe connects the left command's stdout to the right command's
  stdin; it does not carry stderr unless the streams are explicitly combined.
- `head -n 2` limits its input stream to two output lines in this pipeline.
- `>` overwrites stdout output, while `2>>` appends stderr output.
- `~/path` begins at the current user's home directory; `~name/path` is parsed
  as a named-user home expansion when that user exists.
