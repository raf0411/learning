## Concepts covered

- Nano modifies an in-memory buffer; declining to save discards that buffer
  while leaving the existing disk file unchanged.
- `grep` handles each file operand independently, so one invocation can produce
  successful matches on stdout and missing-file diagnostics on stderr.
- A normal pipe connects the left command's stdout to the right command's
  stdin; it does not carry stderr unless the streams are explicitly combined.
- `head -n 2` limits its input stream to two output lines in this pipeline.
- `>` overwrites stdout output, while `2>>` appends stderr output.
- `~/path` begins at the current user's home directory; `~name/path` is parsed
  as a named-user home expansion when that user exists.

### Concepts covered

- A running command has a user identity and one or more group identities.
- Filesystem objects record a type, owning user, owning group, and permission
  mode.
- Linux selects exactly one basic permission class: owner, otherwise group,
  otherwise other. It does not combine classes or fall back to another class.
- Regular-file `r`, `w`, and `x` control reading contents, modifying contents,
  and attempting execution.
- Directory `r`, `w`, and `x` control listing names, changing directory entries,
  and traversal/search by known name.
- Deletion changes an entry in the parent directory, so it depends on parent
  directory permissions rather than the file's write permission.
- Symbolic `chmod` changes mode bits; `chgrp` changes the owning group; `chown`
  changes the owning user and can also change the group.
- Membership in Ubuntu's `sudo` group does not silently elevate an ordinary
  command; `sudo` starts the specified command with another identity, normally
  root.
- Least privilege gives a process only the capabilities it needs instead of a
  broadly privileged identity.
- Numeric modes are another representation of the same `rwx` bits, using
  weights `r=4`, `w=2`, and `x=1`. This node was introduced, but the first
  calculation check was not attempted before session end.
