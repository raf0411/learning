# RESOURCES

## Primary local references

- Ubuntu homelab manual pages: `man <command>`
- Command summaries for the installed version: `<command> --help`
- Installed package documentation: `/usr/share/doc/`

External official documentation will be added when each topic is introduced so
this file remains a short, useful reference rather than a link dump.
