# GOAL

## Immediate career goal

Become employable for an entry-level SysAdmin, Linux Administrator, Cloud
Support, or similar infrastructure role within roughly 3–4 months (target:
late November to late December 2026).

## Job-ready outcomes

By the end of this roadmap, I should be able to:

- administer an Ubuntu server safely from the command line;
- manage files, users, groups, permissions, packages, processes, and services;
- understand and troubleshoot essential TCP/IP, DNS, ports, routing, and SSH;
- use logs and system tools to diagnose common service, resource, storage, and
  connectivity failures;
- configure and secure a small network service, including access controls,
  updates, backups, and basic monitoring;
- automate routine tasks with Bash and keep work in Git;
- operate core compute, networking, storage, IAM, and monitoring features in one
  major cloud platform;
- demonstrate these skills through documented hands-on projects and explain the
  troubleshooting decisions made.

## Constraints and priorities

- Available study time: about 5 hours daily.
- Practice environment: macOS plus an Ubuntu homelab server.
- Prefer hands-on labs and troubleshooting over passive study.
- Prioritize SysAdmin foundations before cloud and DevOps tooling.
- Defer Kubernetes, CI/CD, advanced containers, and advanced infrastructure as
  code until the foundations above are reliable.
