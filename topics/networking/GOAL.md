# GOAL

## Why

Become a DevOps engineer. Networking is the layer every deployment, container,
cloud service, and outage sits on, so I need to understand it well enough to
build, inspect, and troubleshoot it myself.

## Scope (fixed — no more, no less)

Concepts: TCP/IP, IP addressing, subnetting, gateways, routing, ports, SSH, DNS.

Protocols:
1. TCP/IP — the fundamental Internet suite
2. HTTP/HTTPS — web browsing and secure web transfer
3. FTP/SFTP — file transfer
4. SMTP/POP3/IMAP — email
5. DNS — domain name resolution
6. DHCP — automatic IP address assignment
7. SSL/TLS — encrypted communication
8. UDP — fast, connectionless transmission

## Desired capability

- Explain each topic simply, in my own words, and say *why* it exists.
- Use real tools (ip, ping, dig, curl, openssl, ssh, sftp, nc, tcpdump) to
  observe each protocol working and to diagnose when it fails.
- Plan addresses and subnets, and reason about how a packet gets from A to B.

## Success criteria

- Every phase finishes with a hands-on mini-project I complete myself.
- A capstone project that ties every topic together, is reproducible, documented,
  and good enough to show in job interviews as a portfolio piece.

## Constraints / preferences

- Explain complex things as simply as possible; assume no networking knowledge.
- Hands-on first. Mac (macOS) + Ubuntu VM available for labs.
